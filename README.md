A single line of quiet, earned pride: a mother who worked night shifts for
years, finally hearing her child read a bedtime story all the way through
without stumbling once.

Run with Node 22 (pure TypeScript, no dependencies):

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
